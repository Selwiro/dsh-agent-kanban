# 智能体看板

在 DSH 里查看本机多个项目的进度和任务，把任务交给会话执行，由智能体通过看板工具回写结果。

## 它做什么

- 侧栏出现「智能体看板」入口，点击打开跨项目总览主面板。
- 会话顶部「对话 / 轨迹 / 看板」中增加「看板」页，跟随当前会话的工作区显示本项目任务。
- 自动扫描 DSH 已登记的工作区，读取其中的 `management/project.json` 和任务详情。
- 工作区以外的项目，才需要在「工作区外目录」里手动添加。
- 总览显示项目、待办、进行中、阻塞、完成，以及当前最值得处理的任务。
- 项目页按「待办 / 进行中 / 待验收 / 阻塞」四列展示进行中的工作；已完成单独折叠在下方，不会越积越占版面。
- 智能体提交结果后任务进入「待验收」，由你通过或退回；通过后才进入「已完成」。
- 任务详情可查看 Markdown、复制执行指令、打开执行会话。
- 可新建任务、开始任务、完成或标记阻塞；写入格式与网页版和 CLI 相同。
- 在会话的「看板」页点「在新会话执行」，会新建一个该项目目录的 DSH 会话，并把任务指令直接发给智能体，不需要复制粘贴。
- 智能体可调用 `kanban_projects`、`kanban_show`、`kanban_create`、`kanban_start`、`kanban_finish`、`kanban_block`。

## 首次使用

1. 安装后在 DSH 侧栏打开「智能体看板」。
2. 看板会自动扫描 DSH 工作区，工作区里的项目直接出现。
3. 只有项目不在任何 DSH 工作区里时，才点右上角「添加工作区外目录」，选择项目目录或它的父目录。
4. 看板会扫描目录下 4 层以内的 `management/project.json`。移除工作区外目录只取消登记，不改项目文件。

## 任务与智能体

会话顶部的「看板」页跟随当前会话的工作区，显示本项目的任务。点任务详情里的「在新会话执行」会：

1. 在项目目录下新建一个 DSH 会话；
2. 把任务标记为进行中并记录 `session_id`；
3. 直接把执行指令发给智能体，不需要复制粘贴。

智能体完成后调用 `kanban_finish` 提交验收，受阻调用 `kanban_block`，看板每 5 秒刷新一次，并出现「查看会话」入口。任务会先进入「待验收」；你通过验收后才进入「已完成」，退回则重新进入执行。主面板里的任务详情也提供同样的「在新会话执行」。

也可以用「复制指令」手动把任务交给已有会话，或手动开始、完成、标记阻塞。手动开始得到的 `run_id` 会写进复制的指令。

## 数据与权限

- 扫描来源是 DSH 工作区列表，加上手动添加的工作区外目录。
- 只读写项目自己的 `management/project.json` 和 `management/tasks/*.md`。
- 只读项目：索引在项目根目录、`revision` 存在、任务由外部来源维护、项目已结项、目录不可写。界面会显示原因并禁用写操作。
- 任务写回使用原子替换；同一进程内的写操作按项目串行。
- 不另起 HTTP 服务，接口挂在 DSH 自己的 Web 服务器上，只接受同源请求。

## 已知限制

- 工作区里的项目不需要添加；工作区外项目仍需手动添加一次。
- 扫描预算为 10 秒，超大目录可能被截断，界面会提示。
- 自动刷新是 5 秒轮询，不是会话事件推送。
- 只有「在新会话执行」会自动发送任务；「复制指令」仍需粘贴一次。
- 与网页版或 CLI 同时写同一个项目时没有跨进程文件锁，建议不要同时操作同一个任务。
- 只读判定与网页版一致；不修改项目索引的 `revision`。
- 工作区列表来自 DSH 的登记数据；新工作区建立后，刷新即可看到。
